# Generator specification (verbatim)

Source: pasted by the thesis author in chat (2026-10-22), message "Here I have a specification for generating nets of each structural subclass". Reproduced unchanged; see SPEC.md section 5.3 for the decisions made where it is silent.

1. General NetInvariant: None.Generation Specification:Generate a size $\vert{}P\vert{}$ for places and $\vert{}T\vert{}$ for transitions.Generate a random collection of coordinate pairs $(p, t)$ where $p < \vert{}P\vert{}$ and $t < \vert{}T\vert{}$ to define the $P \to T$ arcs. (This can be represented as a flattened boolean matrix or by taking a random sub-sequence of the full cartesian product).Generate a random collection of coordinate pairs $(t, p)$ where $t < \vert{}T\vert{}$ and $p < \vert{}P\vert{}$ to define the $T \to P$ arcs.2. CircuitInvariant: A single, strongly connected cycle alternating between places and transitions.Generation Specification:Generate a strictly positive size $N \ge 1$.Instantiate exactly $N$ places and $N$ transitions (indices $0$ to $N-1$).Map every place index $i$ to transition index $i$ to form the $P \to T$ arcs.Map every transition index $i$ to place index $(i + 1) \pmod N$ to form the $T \to P$ arcs.3. State Machine (SM)Invariant: Every transition has exactly one input place and exactly one output place.Generation Specification:Generate a strictly positive size $\vert{}P\vert{} \ge 1$ and a size $\vert{}T\vert{} \ge 0$.Generate a vector of length $\vert{}T\vert{}$ containing random integers in the range $[0, \vert{}P\vert{} - 1]$. This maps each transition to its single input place.Generate a second vector of length $\vert{}T\vert{}$ containing random integers in the range $[0, \vert{}P\vert{} - 1]$. This maps each transition to its single output place.Map the arcs directly from these two vectors.4. Marked Graph (MG)Invariant: Every place has exactly one input transition and exactly one output transition.Generation Specification:(This is the structural dual of the State Machine)Generate a size $\vert{}P\vert{} \ge 0$ and a strictly positive size $\vert{}T\vert{} \ge 1$.Generate a vector of length $\vert{}P\vert{}$ containing random integers in the range $[0, \vert{}T\vert{} - 1]$. This maps each place to its single input transition.Generate a second vector of length $\vert{}P\vert{}$ containing random integers in the range $[0, \vert{}T\vert{} - 1]$. This maps each place to its single output transition.Map the arcs directly from these two vectors.5. Extended Free Choice (EFC)Invariant: If two places share an output transition, their sets of output transitions must be identical.Generation Specification:Generate sizes $\vert{}P\vert{}$ and $\vert{}T\vert{}$.Generate a structural choice parameter $K \ge 1$, representing the number of equivalence classes (choice classes) for transitions.Generate a vector of length $\vert{}T\vert{}$ containing random integers in the range $[0, K - 1]$. This partitions the transitions into the $K$ disjoint choice classes.Generate a vector of length $\vert{}P\vert{}$ containing random integers in the range $[0, K]$. A value from $0$ to $K-1$ assigns the place to a choice class, while $K$ can represent "no output transitions".For the $P \to T$ arcs: if a place is assigned to class $k$, add an arc from that place to every transition assigned to class $k$.For the $T \to P$ arcs: generate arbitrarily (using the method from the General Net), because EFC only restricts the forward $P \to T$ relations.6. Asymmetric Choice (AC) / Simple NetInvariant: If two places share an output transition, one place's output set must be a subset of the other's. (Their output sets form a laminar family / forest).Generation Specification:Generate sizes $\vert{}P\vert{}$ and $\vert{}T\vert{}$.To guarantee the laminar property, construct a random tree where each node will represent a valid output set. Generate a random tree structure of size $M \ge 1$ (e.g., by generating an array of length $M$ where index $i > 0$ holds a random integer in $[0, i - 1]$ representing its parent).Generate a vector of length $\vert{}T\vert{}$ containing random integers in the range $[0, M - 1]$. This assigns each transition exclusively to one node in the tree.Compute the transition subset for every node in the tree: a node's subset is defined as the union of the transitions assigned directly to it, plus the subsets of all its descendant nodes.Generate a vector of length $\vert{}P\vert{}$ containing random integers in the range $[0, M - 1]$. This assigns each place to a node in the tree.For the $P \to T$ arcs: for every place assigned to node $n$, create arcs to all transitions in node $n$'s computed subset.For the $T \to P$ arcs: generate arbitrarily.
